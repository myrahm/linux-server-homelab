# Linux Server Homelab

A hands-on homelab project focused on developing practical skills in **Linux system administration, networking, security, and infrastructure management** using Ubuntu Server and Oracle VirtualBox.

This project documents the setup, configuration, maintenance, and troubleshooting of a virtualized Linux server environment.

## Tech Stack

- **OS:** Ubuntu Server 26.04.1 LTS (ARM64)
- **Virtualization:** Oracle VirtualBox
- **Networking:** TCP/IP, NAT, DHCP, DNS, SSH
- **Administration:** Linux CLI, Bash, APT, LVM
- **Security:** UFW, Linux permissions, SSH authentication

## Lab Environment

| Component | Configuration |
|---|---|
| Host | Apple M4 Mac |
| Virtual Machine | Ubuntu Server |
| CPU | 2 vCPUs |
| Memory | 2 GB |
| Storage | 25 GB (LVM) |
| Hostname | `sudope` |
| Networking | NAT / DHCP |
